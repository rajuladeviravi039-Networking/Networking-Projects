Enterprise Multi-VLAN Campus Network Configuration

A Cisco IOS configuration for a dual-building redundant campus topology featuring 802.1Q Trunks, Inter-VLAN Routing, HSRP Redundancy, OSPF Area 0, and DHCP Services.

Step 5: First Hop Redundancy (HSRP)

Step 8: DHCP Server Configuration

	Core Switch 1 (CS-1) — Building 1 Subnets

	CS-1(config)# ip dhcp excluded-address 192.168.10.1 192.168.10.10
	CS-1(config)# ip dhcp excluded-address 192.168.20.1 192.168.20.10
	CS-1(config)# ip dhcp excluded-address 192.168.30.1 192.168.30.10

	CS-1(config)# ip dhcp pool VLAN_10
	CS-1(dhcp-config)# network 192.168.10.0 255.255.255.0
	CS-1(dhcp-config)# default-router 192.168.10.1
	CS-1(dhcp-config)# dns-server 8.8.8.8

Step 9: Verification Commands
	
	Execute these privileged EXEC commands to verify control-plane and data-plane health:

	# Verify Trunk Links
	show interfaces trunk

	# Verify VLAN Database
	show vlan brief

	# Verify SVI & Interface IP Status
	show ip interface brief
	
	# Verify First Hop Redundancy State
	show standby brief

	# Verify Routing Table & OSPF Neighbors
	show ip route
	show ip ospf neighbor

	# Verify DHCP Bindings
	show ip dhcp binding
